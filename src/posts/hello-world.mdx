## 📬 Publishing & Newsletter Workflow

1. **Publish on your site first.**  Write the post in MDX, commit, and deploy. Your on-site subscribe forms capture new readers.
2. **Send a ConvertKit broadcast.**  In ConvertKit, create a broadcast:
   - Option A: paste only the intro + “Read the full post →” link (drives traffic & SEO).
   - Option B: paste the full article, but add a canonical link back to the blog.
3. **Optionally automate:** see README for a script that can call ConvertKit’s `/broadcasts` API after each deploy to auto-fill title, excerpt, and link.

This way you own the content and mailing list while readers can still get posts by email.
